# Saigon First 24 Hours

A practical web guide for first-time visitors to Ho Chi Minh City.

## Why this project
Newly arrived travelers often struggle with the same things: getting from the airport, getting a SIM card, paying for things, and avoiding common scams. This guide collects that information in one place.

## Planned features
- "First 24 hours" checklist
- Places and tips by category, with a map
- User ratings and tips
- Feedback form
